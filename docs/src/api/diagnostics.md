# Diagnostics

Discovery helpers that lower the entry barrier: profile a coefficient vector, get an ordered list of resummation methods to try, and tabulate several methods side by side.
These return heuristics and convenience tables — reach for the underlying per-method functions when you want the authoritative numbers.
